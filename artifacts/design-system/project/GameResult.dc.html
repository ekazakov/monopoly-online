  • Same screen as state 1 to 5The game route reads the game from the server. If its status is finished, it shows this screen. Nothing is kept on the device.
  • While it loadsState 6. The page title and the heading do not jump when the result arrives.
  • If the read failsState 7. Try again reads the game once more.
  • No game over event neededA player who was offline, or who closed the tab, sees the same result after a reload. Hot-seat seats come from the game, so This device marks stay right.
  • Sign-out or foreign gameA game the session does not belong to does not show a result. It uses the not-found screen, not this board.

Rules and screen reader notes

  • WinnerThe last active player. Heading: " wins". The winner row has a green edge, a crown icon and the word Winner.
  • Ranks1 is the winner. The others rank by the order they went out: the player who stayed longest is 2. Round numbers show when.
  • Out playersFinal cash, properties and net worth show a dash. Their assets went to the creditor or the bank, so the values are zero.
  • ResignedA resigned seat shows "Resigned · round N". A seat that went bankrupt shows "Bankrupt · round N".
  • This deviceSeats on this device carry the This device tag, as on the lobby boards. The tag is a word, not only a colour.
  • ActionsBack to home is the only action. It is the primary button. There is no save and no share in this version.
  • Heading structureOne h1: " wins". One h2: Final standings. The eyebrow "Game over" is plain text.
  • Focus on loadOn load, focus moves to the h1 (tabindex -1, focus ring shown). The screen reader reads the winner first. Tab goes to Back to home next.
  • TableA real table with a hidden caption, column headers with scope="col" and the rank as a row header. Dashes have a hidden word, "none".
  • Colour is never the only signalPawn colour is the avatar ring. Winner, bankrupt and resigned each have an icon and a word. Avatars have a name and avatar in the label.
  • ContrastInk and ink soft on ground pass 4.5:1. Winner green #3ccf7a and error #ffb4ad pass on #121f2a.
  • Targets and focusButtons are at least 44px high. Focus ring: 2px #e9f0ea, 2px offset (:focus-visible).
  • Reduced motionThe screen has no required motion. A winner reveal or confetti would be off with prefers-reduced-motion. The loading blocks do not pulse.
  • Loading and errorLoading uses role="status" and aria-busy. The error uses role="alert". On error, focus moves to the error heading.
